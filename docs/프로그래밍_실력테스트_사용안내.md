# 코더랜드 프로그래밍 실력 테스트

Python과 C++를 선택해 문제를 읽고, 코드를 작성하고, 테스트 입력으로 실제 실행·채점하는 학습용 웹페이지입니다.

## 과정

| 언어 | 초급 | 중급 | 고급 | 심화 | 합계 |
|---|---:|---:|---:|---:|---:|
| Python 3 | 20 | 20 | 15 | 10 | 65 |
| C++17 | 20 | 20 | 15 | 10 | 65 |

총 130문제, 8개 과정입니다. 각 과정은 100점 만점입니다. C++도 중급 20·고급 15·심화 10문제를 제공합니다.

왼쪽에서 **언어 → 과정 → 문제**를 선택합니다. 문제에는 개념, 표준 입력·출력, 제한, 예제 두 개, 힌트, 해설, 선택 언어의 참고 풀이가 있습니다. 연습 모드에서는 해설을 볼 수 있고 평가 모드는 해설을 숨깁니다.

C++ 초급은 `cin`·`cout`, 자료형과 변수, 정수 연산, 조건문, 반복문, `string`, `vector`, `map`, 정렬을 다룹니다. Python 초급과 같은 과제를 C++로 풀어 두 언어의 문법과 자료구조를 비교할 수 있도록 구성했습니다. Python 기존 65문제의 내용과 ID는 유지합니다.

직접 링크는 Python `#1`~`#65`, C++ `#66`~`#130`입니다. C++ 문제 ID는 `CPP-001`~`CPP-065`입니다. 언어별 코드·메모·진도·채점 기록을 별도로 저장하며 기존 Python 저장 키와 이전 중급 풀이 보관함을 유지합니다.

## 문제·편집기 작업 화면

큰 소개 문구와 장식 요소를 없애고 문제 풀이 작업에 필요한 항목을 배치했습니다.

- PC: 왼쪽 문제 목록, 가운데 문제 본문, 오른쪽 코드 편집기가 기본 표시됩니다. 각 영역은 별도로 스크롤합니다.
- 문제 목록: 언어·난이도 탭과 현재 과정의 문제 검색. 문제 이름·ID·번호로 검색하며 정답 여부를 표시합니다.
- 코드 편집기: 기본 16px, 구문 색상·줄 번호, 상단 예제 실행·전체 채점. 글자 크기는 14/16/18/20px 중 선택하며 브라우저에 저장합니다.
- 가운데 경계선을 드래그하거나 키보드 좌우 화살표로 문제·편집기 너비를 조절합니다. **편집기 확대**는 코드 영역을 넓히며 Esc로 분할 화면에 복귀합니다.
- 모바일: **문제 목록**으로 목록을 열고, **문제 / 코드** 탭으로 전환합니다. 편집기 확대는 전체 화면으로 표시합니다.
- 학습 개념·편집기 도움말·메모는 필요할 때 펼칩니다. 평가 모드는 학습 개념과 힌트·해설을 숨깁니다.

| 키 | 기능 |
|---|---|
| Ctrl+Space | 완성 후보 표시 |
| ↑ / ↓ | 후보 이동 |
| Tab / Enter | 선택 후보 적용 |
| Esc | 후보 닫기 / 확대 화면 해제 |
| Ctrl+Enter | 예제 실행 |
| Ctrl+Shift+Enter | 전체 채점 |

완성 후보는 선택 언어의 함수·키워드·메서드·현재 코드의 식별자입니다. 주석과 문자열 내부, 한글 조합 중에는 후보를 표시하지 않습니다. 완성된 함수의 괄호 안으로 커서를 이동하며, 구문 색상과 저장·실행에 사용되는 실제 코드는 같은 textarea 내용을 사용합니다. 코드 다운로드에 표시용 색상이나 줄 번호가 섞이지 않습니다.

## 실행 및 채점

- 예제 실행은 예제 두 개만 확인합니다. 전체 채점은 문제마다 19개(예제 2개 + 추가 검증 17개)로 검사합니다. 전체 130문제에 2,470개 채점 입력이 포함됩니다.
- 정답 코드와 문자가 같은지 비교하지 않습니다. 실제 실행 결과의 값과 순서를 비교하며 공백·탭·줄바꿈 차이는 허용합니다.
- 틀린 테스트는 입력·기대 출력·내 출력을 확인할 수 있습니다. 긴 입력·출력은 앞 6,000자까지만 표시합니다.
- Python은 기존 Pyodide 엔진을, C++는 동봉한 Clang/LLD WebAssembly 컴파일러와 libc++를 사용합니다. C++ 코드를 실제로 C++17로 컴파일한 뒤 테스트마다 새 WebAssembly 프로그램 인스턴스로 실행합니다.
- 학생 소스 코드를 외부 컴파일 서버나 AI 서비스로 전송하지 않습니다. API 키나 별도 유료 서버가 필요 없습니다.
- 초기 화면에서는 문제 설명과 편집기를 먼저 표시합니다. 테스트 데이터는 전체 채점을 눌렀을 때 해당 언어의 파일만 불러오며, 예제 실행은 별도 테스트 파일 없이 문제에 포함된 예제로 실행합니다.
- Python과 C++ 엔진은 해당 언어의 첫 채점에만 불러옵니다. C++ 컴파일러는 약 77MiB이므로 첫 준비 시간이 길 수 있습니다. 준비 중에도 문제·편집기 사용과 실행 중단이 가능합니다. 같은 페이지에서는 다운로드한 파일을 재사용합니다.
- C++는 준비 최대 180초, 소스 컴파일 최대 120초, 테스트별 실행 최대 15초, 전체 테스트 실행 최대 300초입니다. 컴파일 오류·오답·실행 오류·시간 초과·출력 초과·중단을 구별합니다. 기기에 따라 속도가 달라집니다.
- 이 C++ 환경은 Clang 8.0.1 기반의 WASI/libc++ C++17 학습 환경입니다. 최신 GCC 전체와 동일한 환경이 아니며 스레드, 운영체제 명령, 외부 패키지를 제공하지 않습니다. `bits/stdc++.h`는 자주 사용하는 표준 헤더를 묶은 호환 헤더로 제공합니다. 이 과정의 모든 참고 코드를 실제 엔진으로 검증합니다.
- C++ 문법이 잘못되면 컴파일 메시지가 표시됩니다. 컴파일러를 불러오지 못한 경우는 실행 환경 오류로 표시되며 다시 시도할 수 있습니다.

코드 입력창은 줄 번호, 괄호·따옴표 자동완성, 선택 영역 감싸기, 빈 괄호 쌍 삭제, Tab 4칸 입력, 언어별 Enter 들여쓰기를 제공합니다. C++의 `//`, `/* */` 주석을 인식합니다. Shift+Tab은 편집기 밖으로 초점을 옮깁니다. 코드는 Python `.py`, C++ `.cpp`로 내려받으며 전체 풀이 Markdown에는 두 언어의 코드와 과정별 점수가 포함됩니다.

브라우저 채점과 저장은 학습용입니다. 교사 서버에 답안을 전송하거나 공식 성적을 보증하지 않습니다. 자료에 해설과 테스트가 들어 있으므로 보안 시험 용도로 사용하지 않습니다. 브라우저 데이터를 삭제하기 전에 전체 풀이를 내려받으세요.

## 배포와 학생 전달

**웹:** 저장소의 `releases/프로그래밍_실력테스트_웹배포용.zip`을 풀어 기존 Cloudflare 프로젝트에 모든 파일을 다시 업로드하세요. [Cloudflare의 개별 정적 파일 제한](https://developers.cloudflare.com/workers/platform/limits/)에 맞춰 각 파일은 25MiB 미만이 되도록 컴파일러를 분할했습니다. ZIP 안의 파일명·폴더 관계를 유지하세요. 기존 서버 주소를 바꾸지 않아도 됩니다. 로컬 파일 수정만으로 이미 배포한 사이트가 갱신되지는 않습니다.

**학생 파일 전달:** `releases/프로그래밍_실력테스트_웹배포용.zip`을 모두 풀고 `index.html`을 Chrome/Edge로 열면 됩니다. 모든 엔진 파일이 동봉되므로 압축을 푼 로컬 폴더에서는 인터넷 없이 두 언어를 채점합니다. HTML 파일 하나만 보내면 실행되지 않습니다.

ZIP은 `npm run package`로 생성합니다. Git에는 ZIP 대신 `public/`의 원본 실행 파일을 관리합니다.

## 저장소에서 개발·검증

웹사이트 실행 파일은 `public/`, 로컬 서버·정적 검사·ZIP 생성기는 `scripts/`에 있습니다. 개발은 저장소 루트에서 `npm run dev`, 파일 검사는 `npm run check`, 수동 배포 ZIP 생성은 `npm run package`를 실행합니다. 자세한 구성과 Cloudflare 연결은 [저장소 README](../README.md)를 확인하세요.

현재 제공하는 문제 데이터는 `public/problems.js`와 `public/cpp-problems.js`, 검증 입력은 `public/judge-cases.js`와 `public/cpp-judge-cases.js`입니다. 예전 별도 문제 생성기·브라우저 검증 원본은 현재 작업 디렉토리에 남아 있지 않아 저장소에 포함하지 않았습니다. 과거 개발 단계에서 C++ 65문제의 총 6,955개 입력과 문제 이동·편집·채점·모바일 동작을 검증했으며, 여기의 `npm run check`는 정적 검사를 제공합니다.

컴파일러 원본은 [binji/wasm-clang](https://github.com/binji/wasm-clang)입니다. 원본 Apache/LLVM 라이선스와 변경 고지는 `public/cpp-runtime.LICENSE.txt`에 있으며 Python 엔진 라이선스도 함께 보관합니다.
